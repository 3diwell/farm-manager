# Это открытая выгрузка 3DIWELL Farm Manager

Файл создаётся инструментом выгрузки и отмечает, что это открытый репозиторий, а не закрытый
рабочий. Наборы проверок по нему пропускают то, что относится только к закрытой части (например,
обложки принтеров, историю закрытого репозитория).

This file marks the public 3DIWELL Farm Manager tree. Test suites use it to skip checks that only
apply to the private development repository.
