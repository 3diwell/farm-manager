# Лицензии платных модулей

Сама программа и бесплатные модули работают без лицензий. Лицензия нужна только платным модулям
или платным функциям модуля.

## Как устроена лицензия

- Лицензия — файл `.fmlic` от поставщика модуля. Программа проверяет подпись поставщика и
  хранит файл у себя. Подделанный или повреждённый файл не принимается.
- **Интернет не нужен** ни при добавлении лицензии, ни потом.
- Купленная версия модуля работает **бессрочно**. Новые версии доступны, пока идёт оплаченный
  период обновлений («обновления до …»). Когда он закончится, установленная версия продолжит
  работать, её можно ставить заново; новые версии потребуют продления.
- Бывают лицензии на срок («пользование до …»): после срока платные функции закрываются, данные
  остаются.

## Добавить лицензию

*Настройки → Модули → Лицензии модулей*: вставьте ключ из письма (текст, начинающийся с `FMK1.`),
отметьте согласие на передачу номера лицензии и номера компьютера и нажмите «Добавить ключ». Файл
`.fmlic` добавляется кнопкой «Добавить лицензию из файла». Платные функции открываются сразу, без
перезапуска. Продление — новый ключ или файл: добавьте его так же.

## Отметка у службы лицензий

Когда у компьютера фермы есть интернет (или администратор открыл программу с телефона, у которого он
есть), программа сообщает службе лицензий: этот ключ стоит на компьютере с таким-то номером. В строке
лицензии видно ответ: «служба лицензий: работает (время)», «ОСТАНОВЛЕНА» (ключ уже работает на другом
компьютере — перенос подтверждается в личном кабинете) или «АННУЛИРОВАНА». Что именно уходит, показано
в разделе «Что передаётся»: номер лицензии, номер компьютера, модуль и версии — без имён, принтеров и
данных фермы. Нет интернета — лицензия работает как обычно.

## Без лицензии

Платный модуль без действующей лицензии открывается **только для просмотра**: данные видны и
выгружаются, изменить их или посчитать заказ нельзя. В окне модуля — плашка «Только просмотр». Печать
работает всегда; «Складской учёт» без лицензии просто не списывает филамент.

## Запрос активации

Если лицензия должна быть привязана к этому компьютеру, поставщику нужен номер установки.
*Лицензии модулей → Сохранить запрос активации* сохранит небольшой файл с номером установки,
версией программы и списком модулей — без имён, адресов и данных фермы. Отправьте его поставщику
любым способом; в ответ придёт файл лицензии.

## Если новая версия не ставится

«Эта версия вышла после окончания оплаченных обновлений» — программа не заменит работающую
версию неоплаченной. Работает прежняя версия. Для новой нужно продление лицензии.

## Удалить лицензию

Кнопка «Удалить» в строке лицензии. Платные функции по ней закрываются сразу; данные модулей и
программы не удаляются. Вернуть лицензию можно тем же файлом.

## Перенос на другой компьютер

Храните файлы `.fmlic` отдельно — в резервную копию настроек они пока не входят. Лицензия без
привязки переносится вместе с файлом. Лицензию с привязкой к установке поставщик переиздаёт для
нового компьютера по новому запросу активации.
