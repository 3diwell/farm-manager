# Модули

Модуль — расширение программы: склад филамента, аналитика качества, уведомления в мессенджеры,
расчёт заказа и другие. Всё управление — *Настройки → Модули*.

## Установка и обновление

1. *Настройки → Модули → Установка и обновление → Установить модуль из .zip*.
2. Во встроенном Проводнике выберите файл `.zip` модуля.
3. Перезапустите программу кнопкой «Перезагрузить программу».

Ставится любая версия — новее или старее установленной; данные модуля при этом сохраняются.
Если программа знает версию новее, она предупредит, но установку не отменит. Прежняя версия
модуля сохраняется в папке данных (`modules_previous`).

Модуль из **подписанного** пакета программа сначала проверяет: подпись поставщика и каждый файл.
Повреждённый или изменённый пакет не ставится — работающая версия остаётся на месте.

## Пометки в списке модулей

| Пометка | Что значит |
|---|---|
| есть новее: vX | программа знает более новую версию; этот модуль работает |
| новее программы / часть функций — у администратора | модуль новее программы: новые функции пока только у администратора; обновите программу |
| часть функций не подключена | некоторые функции модуля программа подключить не смогла; поставьте актуальную версию |
| подписан | пакет подписан поставщиком и проверен |
| лицензия действует | платные функции работают |
| платные функции — по лицензии | бесплатная часть работает, для платной нужна лицензия |
| выпуск вне оплаченных обновлений | эта версия вышла после окончания периода обновлений — [licenses.md](licenses.md) |
| Пакет повреждён | файлы подписанного модуля изменились после установки; модуль не запущен, данные целы — установите его заново |
| Подпись неизвестна | пакет подписан ключом, которого эта программа не знает |

## Выключение и удаление

Переключатель в строке модуля выключает его; включить можно тем же переключателем. Удаление
убирает файлы модуля, а его данные в папке данных остаются.
