# Куда Farm Manager выходит в сеть

Эта страница — для тех, у кого на ферме ограничен интернет или настроен брандмауэр. Здесь
перечислены все соединения программы: с принтерами в сети фермы и с интернетом.

## Сама программа

- Окно программы и телефон подключаются к ней по порту, выбранному при установке (обычно 8000).
- Пока в «Настройки → Система → Сеть и доступ» выключен «Доступ из локальной сети», программа
  слушает только этот компьютер. Включённый доступ открывает тот же порт для других устройств в
  сети фермы.

## Принтеры (только сеть фермы)

| Принтеры | Как программа с ними говорит |
|---|---|
| Bambu Lab | MQTT по TLS, порт 8883; файлы — FTPS, порт 990; камера — по протоколу производителя |
| Klipper (Moonraker) | HTTP, порт 7125 (или указанный в карточке принтера); камера Creality K1/K2 — WebRTC: служба Creality, порт 9999, и HTTPS 443 или HTTP 8000/80 |
| FlashForge Adventurer 5M / 5M Pro | HTTP, порт 8898; камера 5M Pro — HTTP, порт 8080 |
| Creality на заводской прошивке | родная служба Creality, порт 9999; файл печати — HTTP, порт 80; камера — WebRTC (HTTPS 443 или HTTP 8000/80) или MJPEG, порт 8080 |

Видео камер по WebRTC идёт напрямую между окном программы и принтером в сети фермы: программа не
обращается к внешним серверам (STUN) ни в окне камеры, ни в видеостене.

Кнопка «Найти в сети» слушает объявления принтеров: UDP 2021 и 1990 (Bambu Lab), 5353
(mDNS) и 1900 (SSDP), и задаёт стандартный вопрос «представься» (тот же, что задают сама
Windows и фирменные программы марок). Перебора адресов и портов нет, команд принтерам нет.

## Интернет

| Что | Куда | Когда | Как выключить |
|---|---|---|---|
| Проверка обновлений | https://3diwell.com/farm/latest.json | при открытом окне программы — раз в 6 часов | «Настройки → Общие → Проверять обновления» |
| Тексты сообщений Bambu Lab | https://e.bambulab.com/query.php | не чаще раза в неделю | выключателя нет; без интернета программа берёт сохранённые тексты |
| Модуль «Уведомления в мессенджеры» | Telegram, MAX, VK, WhatsApp — только настроенные каналы | при событиях фермы | выключить канал или модуль |
| Служба лицензий | пока не подключена | — | — |

Проверка обновлений отправляет только обычный запрос файла: ни данных фермы, ни сведений о
принтерах в нём нет. Запрос текстов Bambu Lab — это скачивание общей таблицы с сайта
производителя, без сведений о ваших принтерах.

## Коды доступа принтеров на этом компьютере (принятый риск)

Коды доступа принтеров (у Bambu Lab — «Access Code») программа хранит открытым текстом в базе
`farm_printers.db` и в её ежедневных копиях в папке `backups`. Так же их хранят Bambu Studio,
OrcaSlicer и Home Assistant: программа сама подключается к принтерам после перезапуска, поэтому
ключ шифрования всё равно лежал бы на этом же компьютере. Шифрование средствами Windows (DPAPI)
сознательно не включено: после переустановки Windows или сброса пароля учётной записи все коды
стали бы нечитаемыми, и их пришлось бы вводить заново для каждого принтера.

Что это значит на практике:

- папку данных (по умолчанию `%LOCALAPPDATA%\3DIWELL`) читают только ваша учётная запись Windows
  и администраторы компьютера;
- не отправляйте `farm_printers.db` и папку `backups` посторонним и не выбирайте папку данных на
  облачном диске;
- для переноса на другой компьютер используйте резервную копию настроек с паролем — внутри неё
  коды зашифрованы (см. [backup.md](backup.md));
- код Bambu Lab открывает доступ к принтеру только из сети фермы.
