# Установка и обновление

Относится к 3DIWELL Farm Manager Beta 3.71 (октябрь 2026).

## Что нужно

- Windows 10 или 11, 64-разрядная.
- Права администратора на время установки.
- Принтеры в той же локальной сети, что и компьютер фермы.

Интернет для работы программы не нужен.

## Сначала проверьте, что файлы целы (SHA-256)

Установщик пока без цифровой подписи, поэтому Windows не может сама подтвердить, что файл цел.
Рядом с установщиком лежит `SHA256SUMS.txt` — контрольные суммы всех файлов выпуска: они
показывают, что файлы скачались без порчи. Суммы лежат в той же папке, что и установщик, поэтому
от подмены всей папки они не защищают — берите выпуск только по ссылке от 3DIWELL. Откройте папку выпуска в Проводнике, наберите в адресной строке
`powershell`, нажмите Enter и вставьте одну строку:

```powershell
Get-Content SHA256SUMS.txt -Encoding UTF8 | ForEach-Object { $h, $f = $_ -split '  ', 2; if ((Get-FileHash -LiteralPath $f).Hash -eq $h) { 'OK   ' + $f } else { 'BAD  ' + $f } }
```

Напротив каждого файла должно стоять `OK`. `BAD` или ошибка — файл не запускайте, скачайте заново
и напишите в поддержку. `-Encoding UTF8` нужен обязательно: без него Windows PowerShell 5.1 искажает
русское имя папки клиента. Один файл можно проверить командой `Get-FileHash <файл>` и сравнить
число с его строкой в `SHA256SUMS.txt` (регистр букв не важен).

## Установка

1. Запустите `3DIWELL_Farm_Manager_Setup_<версия>.exe` обычным двойным щелчком, а не через
   «Запуск от имени администратора»: так порт запишется в настройки вашей учётной записи, даже
   если права администратора у другой. Разрешение администратора Windows спросит сама.
2. Прочитайте страницу лицензии: ядро программы распространяется по Mozilla Public License 2.0.
3. Выберите папку установки (по умолчанию `C:\Program Files\3DIWELL Farm Manager`).
4. Страница «Порт программы»: «Автоматически» — порт 8000, а если он занят, ближайший свободный;
   «Задать порт вручную» — любой номер от 1024 до 65535. Установщик откроет в брандмауэре Windows
   именно получившийся порт. Какой порт получился, видно в *Настройки → Система → Сеть и доступ*,
   строка «Порт сервера».
5. Если на компьютере нет .NET Framework 4.7.2+ или Microsoft Edge WebView2 Runtime, установщик
   поставит их сам.

## Если Windows не даёт запустить установщик

- **SmartScreen** — окно «Система Windows защитила ваш компьютер» (издатель неизвестен): так
  Windows встречает любую программу без цифровой подписи. Если суммы сошлись (раздел выше),
  нажмите «Подробнее» → «Выполнить в любом случае».
- **Smart App Control** («Интеллектуальное управление приложениями») — Windows пишет, что запуск
  заблокирован. Разрешить в нём отдельную программу нельзя: Microsoft прямо пишет, что обойти эту
  защиту для одного приложения сейчас невозможно
  ([What is Smart App Control](https://support.microsoft.com/en-us/topic/what-is-smart-app-control-285ea03d-fa88-4d56-882e-6698afdb7003)).
  Поставить программу можно, только выключив защиту: *Параметры → Конфиденциальность и защита →
  Безопасность Windows → Управление приложениями/браузером → Smart App Control*. Это защита всего
  компьютера — решение за вами. По словам Microsoft, после последних обновлений Windows её можно
  включить обратно без переустановки системы. На только что установленной Windows 11 она сначала
  работает в режиме оценки и установке не мешает. Полностью эту сложность снимет только цифровая
  подпись программы — она в планах.

После установки на рабочем столе и в меню «Пуск» появится ярлык «3DIWELL Farm Manager» — он
открывает программу в собственном окне. Ярлык «… — браузер» открывает её в обычном браузере.

Рядом с программой устанавливаются `LICENSE.txt` (текст MPL 2.0) и `THIRD_PARTY_NOTICES.txt`
(сторонние компоненты и их лицензии).

## Где лежат данные

Принтеры, проекты, настройки, журналы и данные модулей хранятся в папке
`%LOCALAPPDATA%\3DIWELL`, а не в папке программы. Поэтому обновление и переустановка их не
трогают. Папку данных можно сменить в *Настройки → Система → Хранение данных*.

## Обновление

Запустите установщик новой версии поверх установленной. Папка данных, принтеры и модули
сохраняются. Перед обновлением полезно сделать резервную копию настроек —
[backup.md](backup.md).

**Порт при обновлении.** Если программа работала на своём порту (не 8000), на странице «Порт
программы» выберите «Задать порт вручную» и введите этот номер. «Автоматически» снова начинает с
8000 и может сменить порт — тогда другие компьютеры и клиент перестанут открывать программу по
прежнему адресу.

## Доступ с других компьютеров

Сразу после установки программа открывается только на этом компьютере. Чтобы открыть её с
других компьютеров сети или из клиента: включите вход по паролю и создайте администратора
(*Настройки → Система → Доступ и аудит*), затем включите «Доступ из локальной сети» (*Настройки →
Система → Сеть и доступ*). Там же появится «Адрес для других компьютеров». Правило брандмауэра
установщик создаёт на порт, выбранный при установке; если позже смените порт в программе, новый
порт в брандмауэре разрешите вручную.

## Клиент для второго компьютера

`3DIWELL_Farm_Manager_Client_Setup_<версия>.exe` ставит только окно программы, которое
подключается к Farm Manager на другом компьютере сети. Сервер, базы и принтеры остаются на
компьютере фермы.
