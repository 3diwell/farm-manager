# Резервные копии

## Резервная копия настроек

*Настройки → Система → Резервная копия настроек* (доступно администратору).

В копию входят: настройки Farm Manager, принтеры и данные их подключения, данные установленных
модулей, которые умеют сохраняться: складской учёт (вместе с кодами QR, метками NFC и
подготовленными наклейками), заказы «Расчёта заказа» с их ставками и настройками, настройки
уведомлений в мессенджеры. Отключённые модули тоже входят в копию. Проекты и задачи в копию не
входят и при восстановлении не меняются. Какие данные каждого модуля входят, окно показывает
прямо перед созданием копии.

- Копию можно защитить паролем. Потерянный пароль восстановить нельзя.
- Копия без пароля содержит данные подключения принтеров — храните файл в надёжном месте.
- Папка данных, папка архивов и порт сервера относятся к компьютеру и при восстановлении не
  меняются.
- Пользователи и пароли входа в копию не входят. Если в копии включена защита входом, а на этом
  компьютере нет администратора, защита останется выключенной — план восстановления скажет об
  этом; создайте администратора в «Доступ и аудит».
- Если данные модуля сюда не ложатся — номер заказа из копии уже занят на этом компьютере другим
  заказом, модуль здесь старее копии или ещё ни разу не запускался, — план назовёт причину, а
  кнопка «Восстановить» станет недоступна. Можно устранить причину и выбрать копию снова, а можно
  нажать «Восстановить без модуля …»: остальное восстановится, а данные этого модуля на
  компьютере останутся как есть. «Вернуть в восстановление» отменяет исключение.
- После восстановления программу нужно перезапустить.

## Что в копию пока не входит

- файлы моделей, приложенные к заказам «Расчёта заказа» (сами заказы входят);
- данные прежней «Себестоимости печати» из старых копий 2.x — программа 3.0 их не использует;
- темы «Оформления» и камеры «Видеостены» (они хранятся в браузере компьютера);
- ключи ботов уведомлений — на другом компьютере каналы подключаются заново;
- файлы самих модулей — модули ставятся заново из `.zip`;
- файлы лицензий `.fmlic` — храните их отдельно.

## Ежедневные копии баз

Программа сама каждый день сохраняет копии всех своих баз — и основных, и баз модулей
(склад, расчёт заказа, качество, уведомления) — в папку `backups` внутри папки данных
(по умолчанию `%LOCALAPPDATA%\3DIWELL\backups`). Копия делается при запуске и проверяется раз
в час, поэтому ферма, которая работает неделями без перезапуска, тоже получает копию каждый
день. Для каждой базы хранятся последние 30 копий.

В копию базы уведомлений попадают ключи ботов мессенджеров — они лежат в той же папке данных
этого компьютера и никуда не отправляются.

## Смена папки данных

*Настройки → Система → Хранение данных → Папка данных → Выбрать…* (доступно администратору).

- Выбирайте пустую папку: если в ней уже есть базы Farm Manager, программа откажется, чтобы
  старые данные не подменили рабочие.
- Смена применяется после перезапуска. Программа переносит базы, модули, лицензии, номер
  установки, файлы проектов, задач и заказов, копии баз и журнал. Каждый файл сначала
  копируется, копия сверяется с оригиналом, и только потом оригинал удаляется.
- Для переноса нужно свободное место не меньше объёма папки данных — **даже если новая папка
  на том же диске**: программа сначала копирует всё и сверяет копии, а оригиналы удаляет только
  потом. Сколько нужно и сколько свободно, программа напишет в «Хранении данных», если места
  не хватит.
- Перенос идёт при запуске, до того как программа откроется. Большая папка (гигабайты файлов
  проектов и задач, медленный или сетевой диск) переносится несколько минут. Всё это время
  окно перезапуска показывает «Переносится папка данных»; программу не закрывайте и не
  снимайте в диспетчере задач. Если окно всё же написало, что подключиться не удалось, —
  подождите и нажмите «Повторить подключение».
- Если что-то не удалось (не хватило места, файл не прочитался), ничего не удаляется:
  программа продолжает работать из прежней папки, показывает причину в «Хранении данных» и
  повторяет перенос при следующем запуске. Чтобы отказаться от переноса, выберите нынешнюю
  папку ещё раз.
- Не переносятся: настройки запуска `config.json` (они всегда лежат в
  `%LOCALAPPDATA%\3DIWELL`), кэш превью и временные файлы. Файлы, которые программе не
  принадлежат, остаются на месте.
- Подробный итог — файл `data-move-report.json` в новой папке (и копия в прежней).
