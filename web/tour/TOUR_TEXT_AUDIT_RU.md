# Ревизия текстов обучения — этап 17

Проверены все 35 пунктов обучения. Цель этапа — не менять механику тура, а привести тексты к единому стилю оператора 3D-фермы.

## Единая терминология

| Термин | Использование |
|---|---|
| файл печати | готовый g-code / 3MF, который можно отправить на принтер |
| модель | STL / STEP или другой файл, который ещё нужно нарезать |
| плита | набор деталей внутри одного файла печати |
| На плате | сколько конкретной детали печатается одним файлом |
| Нужно | требуемое количество деталей |
| Напечат. | принятое готовое количество |
| перепечатка | повторная печать детали после брака / rework |
| Quick Tasks | название раздела интерфейса, оставлено без перевода |

## Что изменено в текстах

- Длинные карточки сокращены; подробности оставлены в блоке «Подробнее».
- Термины «файл», «модель», «файл печати», «плита» разведены по смыслу.
- Блок проектов переписан в производственной логике: заказ / партия, счётчики, плита, Label Objects, перепечатка.
- Quick Tasks описан как быстрый запуск отдельных файлов без создания проекта.
- Тексты диагностики и доступа стали короче и понятнее для оператора.
