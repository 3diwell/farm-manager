# FM Клиент 0.5 — проверка NFC на Redmi Note 14S

Файл: `dist/FM-Client-0.5.0-debug.apk` (около 66 МиБ).

## Установка

1. Завершите текущую операцию в клиенте, если она выполняется.
2. Перенесите APK на телефон и откройте файл. Подтвердите обновление установленного FM Клиента.
   Не удаляйте прежнее приложение и не очищайте его данные. Подпись совпадает с APK 0.4;
   сохраняется тот же идентификатор приложения, повышен versionCode с 4 до 5.
3. Если Android не предлагает обновление, не удаляйте приложение — пришлите текст ошибки.
4. Модуль склада и ядро FM для этой проверки обновлять не требуется.

## Проверка катушки

1. Включите NFC и разблокируйте телефон.
2. Запустите FM Клиент. На экране входа нажмите «Проверка NFC» — подключаться к ферме не нужно.
   Если уже вошли в FM: «Ещё» → «Проверка NFC».
3. Нажмите «Начать проверку». Поднесите заднюю часть телефона к метке одной катушки Bambu.
   Медленно меняйте положение телефона, удерживая рядом несколько секунд. Другие метки
   уберите подальше; при необходимости снимите металлический чехол. Не используйте банковские карты.
4. После обнаружения считывание остановится и появится отчёт. Нажмите «Скопировать отчёт»
   и вставьте его в переписку. Вместо этого можно прислать скриншот результата.
5. Можно проверить другую сторону той же катушки: сначала отведите телефон, затем нажмите
   «Проверить ещё раз». Каждый результат копируйте отдельно, отмечая сторону катушки.

Если за 45 секунд метка не найдена, появится подсказка. Попробуйте другое положение телефона.
Отсутствие отклика само по себе не доказывает несовместимость.

## Что покажет результат

- Наличие и состояние NFC на телефоне.
- UID обнаруженной метки в HEX без изменения порядка байтов Android.
- Обнаруженные технологии, для NFC-A — ATQA и SAK.
- Доступен ли MIFARE Classic для этой пары «телефон + метка»; если доступен — размер памяти.

ВАЖНО: это диагностика обнаружения, а не полноценное чтение филамента Bambu.
Материал и цвет пока не извлекаются. Ключи и чтение защищённых секторов не проверяются.
UID не доказывает производителя, подлинность или уникальность катушки.
Отсутствие MIFARE Classic может означать другой тип метки либо ограничение телефона.
Автоматическое чтение NDEF специально отключено; отсутствие Ndef в списке здесь ожидаемо.

## Безопасность

Метка не изменяется. Экран не отправляет запросы в FM, не создаёт катушки и не меняет остатки
или привязки. Считывание прекращается после результата, по кнопке остановки, через 45 секунд
или при уходе с экрана. При возвращении нужно снова нажать кнопку.
Найденный UID не отправляется автоматически; отчёт копируется только по вашему нажатию.
Камера, QR, складские операции и прежние функции печати клиента сохранены.

Проверка на реальном Redmi и заводской метке остаётся за пользователем. Программные проверки
и сведения о сборке приведены в `VALIDATION_NFC_0.5.md`.
