# Android 0.12.0 — вход до 8 часов без изменения ядра

Установите `dist/FM-Client-0.12.0-debug.apk` поверх установленного Farm Manager.
Не удаляйте приложение и его данные: так сохранятся настройки и журнал незавершённых операций.
На экране подключения отметьте **«Запомнить вход на 8 часов»**, введите обычные логин и пароль
и подключитесь. По умолчанию опция выключена, выбранное значение запоминается для следующих входов.

При новом запуске приложение проверит сеанс у того же FM и загрузит склад.
Проверка идёт одновременно с заставкой. Если заставка выключена в настройках, остаётся только
реальное время подключения; дополнительной задержки на анимацию нет.

## Поведение

- Срок — максимум 8 часов с момента входа. Если FM выдаёт более короткий срок, применяется он.
  Повторные запуски и сетевые запросы не продлевают сохранённый срок.
- Перезапуск FM, отзыв доступа или истечение срока потребуют нового входа. Сеансы ядра
  находятся в памяти сервера; клиент не может сохранить их после перезапуска FM.
- При отсутствии связи сохранённый вход остаётся на телефоне. Экран предлагает повторить
  подключение либо удалить сохранённый вход и войти с другим аккаунтом/адресом.
- «Выйти» сначала удаляет локальный сохранённый сеанс, затем пытается завершить сеанс на FM.
  Без сети локальный выход всё равно выполняется; удалённый сеанс завершится по правилам FM.
- Сеанс другого адреса, порта или схемы HTTP/HTTPS не используется. Сохранённый файл сам по себе
  не даёт доступ к складу: требуется успешная проверка `/api/auth/status` и загрузка данных.
- Ответ 401 или явное `authenticated:false` удаляет сохранённый вход. Ответ 403, ошибка сервера,
  недоступная сеть и некорректный ответ не трактуются как неверный пароль.
- Ошибку чтения/расшифровки приложение обрабатывает возвратом к обычному входу. Если сохранить
  новый вход не удалось, приложение сообщает об этом; текущий вход продолжает работать в памяти.
- Без сохранения входа пароль снова потребуется после потери процесса. Настройка выключения
  приветственного экрана действует независимо от авторизации.
- При отключённой авторизации на сервере сохранять нечего: защищённый сеанс не создаётся.

Пароль не записывается на диск. Сохраняется только текущая cookie `fm_session`, адрес FM,
исходное время входа, неизменяемый срок и признак HTTPS. Данные шифруются AES-256-GCM с новым
случайным IV при записи; ключ создаётся в Android Keystore. Файл находится в `noBackupFilesDir`,
резервное копирование и перенос данных приложения по-прежнему отключены.
Шифрование хранения не меняет свойства HTTP: для HTTP по-прежнему нужна доверенная сеть фермы.
Системная проверка HTTPS-сертификатов сохранена.

Ядро FM, серверный модуль, анимация, тексты приветствий, QR/NFC и протокол склада не изменены.
Сохранение входа не запускает повтор незавершённых складских операций: журнал остаётся прежним,
повтор выполняется только по действию пользователя.

## Устройство реализации

- `SavedSession`: проверяемые поля, предел 8 часов и абсолютный срок, отказ при часах раньше входа.
- `SessionCipher`: версионированное шифрование с проверкой целостности всех сохранённых полей.
- `EncryptedSessionStore`: Android Keystore, ограниченный размер файла, атомарная запись,
  удаление повреждённой записи; операции с ключом выполняются вне главного потока.
- `RememberedLogin`: обязательная проверка сеанса сервером, раздельная обработка отзыва и сбоя связи.
- `FmApi`: экспорт только cookie с известным сроком, импорт только для того же адреса,
  контроль срока перед запросами и отдельная ошибка истечения авторизации.
- `MainActivity`: опция входа, проверка во время заставки, повтор подключения, локальное удаление
  перед выходом. Результат подключения показывается после закрытия заставки, не обрывает её.

Срок на клиенте использует системное время телефона; сервер остаётся источником решения
о действительности сеанса. Долговременного токена устройства и обновления сеанса в фоне нет.

## Проверки и проверка на телефоне

Результаты автоматических проверок и контрольные суммы: `VALIDATION_MOBILE_0.12.md`.
Подключённого Android-устройства и эмулятора в этой среде нет. Работа Android Keystore,
холодный запуск, переход после заставки и восстановление после перезагрузки телефона
требуют проверки на настоящем устройстве; JVM-тесты не подменяют эту проверку.

1. Установить APK поверх предыдущего, включить сохранение входа, войти, закрыть процесс
   приложения и открыть снова. Должен открыться склад без ввода логина и пароля.
2. Повторить с выключенным приветственным экраном: анимации быть не должно.
3. Закрыть приложение, временно отключить Wi-Fi, открыть: должен появиться повтор подключения.
   Вернуть сеть и повторить — пароль до истечения срока не требуется.
4. Нажать «Выйти», в том числе при отключённой сети, закрыть процесс и открыть снова:
   должна появиться форма входа.
5. Перезапуск FM и ожидание более 8 часов после входа должны приводить к повторной авторизации.
6. Войти без отметки сохранения и закрыть процесс: следующий запуск снова показывает форму.
7. Проверить восстановление после перезагрузки телефона в пределах срока при работающем FM.
