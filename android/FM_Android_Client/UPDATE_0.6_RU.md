# FM Клиент 0.6 — пробное чтение заводской метки Bambu

Файл: `dist/FM-Client-0.6.0-debug.apk`.

## Установка и проверка

1. Установите APK как обновление поверх FM Клиента 0.5, без удаления приложения и его данных.
2. Откройте «Проверка NFC» с экрана входа либо через «Ещё». Подключаться к FM не нужно.
3. Нажмите «Прочитать данные Bambu» — откроется отдельный экран с описанием теста.
4. На этом экране нажмите «Прочитать данные Bambu», затем приложите телефон к той же
   заводской метке катушки, которая ранее определилась как UID `F6B582CA`.
5. Держите телефон неподвижно до результата. Не убирайте его сразу после обнаружения метки:
   теперь после обнаружения выполняется чтение данных. Оно ограничено 15 секундами.
6. Нажмите «Скопировать отчёт» и пришлите результат сюда, даже если чтение завершилось ошибкой.
   При необходимости отведите телефон, измените положение и повторите по кнопке.

Модуль склада и ядро FM обновлять не нужно. Запись в метку, привязки катушек и приёмка
из этого экрана не выполняются. Используйте только свои заводские метки филамента Bambu;
не прикладывайте карты оплаты, пропуска и другие посторонние метки.

## Что ожидаем увидеть

Для сверки пользователь сообщил: Bambu Lab, предположительно PETG Basic, Orange, 1,75 мм.
Эти сведения НЕ используются для распознавания и НЕ подставляются при ошибке чтения.
В результате могут появиться материал, разновидность, коды материала/варианта, RGBA основного
цвета, диаметр и заводская масса. Название Orange не выводится как считанный факт: в читаемых
полях находится код цвета. Для удобства рядом показывается экранный образец этого цвета.
Заводская масса не считается текущим остатком. Дополнительные цвета и подлинность RSA-подписи
на этом этапе не проверяются.

## Если возникает ошибка

- «Доступ к сектору … не получен»: не подтверждено чтение по известному алгоритму.
  Причиной может быть другой формат/ключи или потеря связи. Ключи не перебираются.
- «UID … не совпадает»: результат отвергнут, поля не подставляются.
- «Не соответствует … формату» / «вне … диапазона»: блоки доступны, но разбор не подтверждён.
- «Тайм-аут» / потеря связи: отведите телефон и попробуйте снова, удерживая его у метки.
- «Не поддержан»: текущий тест рассчитан только на MIFARE Classic 1K с UID 4 байта.

Отчёт показывает этапы чтения, но не включает ключи или полный дамп. Он никуда не отправляется
автоматически. После результата, остановки или сворачивания считывание прекращается.
Автоматическое возобновление отсутствует — каждый тест запускается по кнопке.

Это экспериментальный считыватель по публично исследованному формату, не официальный SDK Bambu.
Реальную совместимость подтвердит результат вашего телефона. Старые APK сохранены.
