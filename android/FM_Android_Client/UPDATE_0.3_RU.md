# FM Клиент 0.3 — оформление и общий PDF с QR

## Установка

Установите `dist/FM-Client-0.3.0-debug.apk` поверх прежнего клиента. Не удаляйте приложение
и не очищайте его данные. Новый APK содержит и функции снятия/замены из 0.2.

Для дизайна и PDF ядро FM менять не нужно. Если модуль `mobile-prototype-0.2` уже установлен,
повторно устанавливать его не требуется. Если у вас ещё 0.1, приёмка и PDF работают;
для снятия/замены понадобится модуль 0.2 по инструкции `UPDATE_0.2_RU.md`.
Перед любым обновлением закончите сохранённую незавершённую операцию.

## Оформление

- Палитра основного FM: графитовые панели, голубой акцент, линейные иконки.
- «Склад»: приёмка, установка/замена, снятие; счётчики катушек.
- «Катушки»: поиск по материалу, цвету, подписи или ID, собственные QR.
- «Партии»: текущая приёмка и предыдущие партии, общий PDF.
- «Ещё»: QR позиций, переключение тёмной/светлой темы и выход.
- Камера: контекст операции, направляющая рамка, фокус по касанию, фонарик при наличии.
- При выборе готового материала поля создания нового скрыты.

## Приёмка нескольких катушек и один PDF

1. Откройте «Партии» → «Начать новую партию» и подтвердите.
2. Выберите место хранения, сканируйте катушку, проверьте поля и подтвердите приёмку.
3. Нажмите «Следующая катушка». Место остаётся тем же; сканируйте и принимайте следующие.
4. Откройте «Партии», выберите текущую партию → «Скачать все QR одним PDF».
5. В системном окне выберите «Загрузки» или другое место и нажмите «Сохранить».
6. Откройте файл и распечатайте A4 в масштабе 100%. На странице восемь меток с QR,
   подписью и индивидуальным ID. Наклеивайте каждую на соответствующую катушку.

Если начать обычную приёмку без создания партии, первая партия создастся автоматически;
дальнейшие приёмки будут попадать в неё, пока вы явно не начнёте новую. Предыдущие партии
не удаляются. Можно собирать в одной партии разные материалы и разные места хранения.

Каждая катушка подтверждается отдельно: это партия этикеток, не одно массовое начисление
остатков по количеству. В списке только успешно принятые катушки. Ошибка следующего
сканирования не отменяет предыдущие приёмки. После обрыва повторяйте сохранённый запрос:
приёмка и этикетка не дублируются.

## QR уже существующих катушек

«Катушки» → «Скачать несколько QR» → отметьте нужные катушки → «Скачать PDF».
Есть поиск, счётчик выбранных и «Выбрать все / снять выбор». Выбор сохраняется при фильтрации;
кнопка «Выбрать все» включает также скрытые поиском катушки. Экспорт ничего не меняет в складе.

## Ограничения и проверка

- До 500 катушек в одном PDF. Формат — A4, не рулонные термоэтикетки.
- Партии сохраняются только на этом телефоне. После удаления приложения/его данных
  локальная история пропадёт; сами катушки останутся в FM и их QR можно выбрать заново.
- История содержит подписи на момент приёмки. Последующее редактирование/удаление в FM
  не переписывает старую партию; перед перепечаткой старой истории сверяйте катушки.
- Длинная подпись на этикетке может быть сокращена; индивидуальный ID печатается отдельно.
- Отмена сохранения PDF не отменяет складскую приёмку. PDF всегда можно сохранить снова.
- Снятие/замена 0.2 ещё ожидают вашей реальной проверки. Новый интерфейс, сохранение PDF
  и чтение бумажных меток также нужно проверить на телефоне; автоматические тесты этого не заменяют.

Для первой пробы примите две тестовые катушки, сохраните общий PDF, проверьте два разных
ID и сканирование обоих QR. Затем проверьте девять катушек: должно быть два листа без дублей.
