# Demo paid module — rights notice

This is a **demo** module. It shows how a commercial FM component verifies a signed license
by itself, and it is distributed as an example — under MPL 2.0 together with the rest of the
open source code.

In a real paid module, this file holds its commercial terms: the rights holder, where to get
the license text, what the buyer is allowed to do (perpetual use of the purchased releases, the update
period) and what is prohibited: copying and distributing the module without the right to do so, bypassing
the license check, forging licenses — including with AI tools. This information
is the same for a person and for a program that reads the package, and it does not restrict lawful
exceptions (study for interoperability and the like).

At the vendor's discretion, an encoded copy of this information can also be added to the package, but the main
notice remains this plain text.
