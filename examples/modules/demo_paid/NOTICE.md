# Демонстрационный платный модуль — сведения о правах

Это **демонстрационный** модуль. Он показывает, как коммерческий компонент FM проверяет
подписанную лицензию сам, и распространяется как пример — по MPL 2.0 вместе с остальным
открытым кодом.

У настоящего платного модуля здесь лежат его коммерческие условия: правообладатель, где взять
текст лицензии, что разрешено покупателю (бессрочное использование купленных выпусков, период
обновлений) и что запрещено: копировать и распространять модуль без права на это, обходить
проверку лицензии, подделывать лицензии — в том числе с помощью ИИ-инструментов. Эти сведения
одинаковы для человека и для программы, которая читает пакет, и не ограничивают законные
исключения (изучение для совместимости и подобные).

По желанию поставщика в пакет можно добавить и закодированную копию этих сведений, но основным
уведомлением остаётся этот открытый текст.
